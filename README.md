# 同舟 · 校园手账

把同济校历、学校通知和 Canvas / 课堂派 / Educoder 作业，收进一个页面。

## 功能

- **校历**：课程、假期、调课、DDL 一页看完
- **学校通知**：同步学校门户通知，支持已读/未读
- **作业**：聚合多个平台，显示完成状态
- **自动登录与同步**：填好账号密码后自动登录、后台同步
- **托盘常驻**：关闭网页后仍在后台运行
- **Windows 通知**：提醒未完成作业和登录失败，点击打开作业页
- **设置页**：账号配置、检查更新、关于

## 运行

需要 Windows 10/11、Node.js 18+ 和 Edge。

### 方式一：安装程序（推荐）

双击 `tongji-hub-setup-ver.0.18.exe`：

1. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\TongjiHub`）
2. 决定是否开机自动启动
3. 点击「安装」，完成后创建桌面和开始菜单快捷方式

安装后可直接在应用内更新到新版本。

### 方式二：从源码运行

1. 下载仓库源码
2. 双击 `启动同舟.vbs`
3. 首次运行会自动安装依赖，稍等片刻
4. 浏览器打开 `http://127.0.0.1:4173`

也可以双击 `desktop\start-tray.bat`。

右键托盘图标可以：

- 打开界面
- 立即同步作业
- 退出

Windows 11 可能把图标收在右下角 `^` 里。

## 设置

- **账号配置**：填写各平台账号密码，支持「保存并登录」和「全部保存并登录」
- **检查更新**：手动检查新版本；发现更新后可一键下载并自动替换、重启
- **关于**：开发者、GitHub、致谢和访问统计
- **开机启动**：双击 `设置开机启动.vbs`；再次运行可取消

## 数据与隐私

- 账号密码、登录态、作业和课表快照保存在本机 `.data`
- 账号密码为明文保存，仅建议在自己的电脑上使用
- 不要把 `.data` 文件夹发给别人
- 发布 zip 不包含 `.data`

## 常见问题

**提示缺少 Node.js**  
按弹窗提示下载安装 Node.js 18 或更高版本，然后重新启动。

**网页打不开或 404**  
确认托盘程序在运行；重新双击 `启动同舟.vbs`。

**没有弹出通知**  
检查 Windows 通知设置，关闭“请勿打扰”。

**托盘图标找不到**  
点任务栏右下角 `^`，或在“设置 → 个性化 → 任务栏 → 其他系统托盘图标”里打开。

**同步失败**  
启动同步失败会自动重试 3 次，每次间隔 30 秒；仍失败请检查通知或重新登录平台。

## 版本

当前版本：`ver.0.18`。

功能更新升级到下一个 `ver.0.xx`；纯补丁不单独升级版本。发布包放在 `releases/`。

### 自动更新

网页启动时会读取远程 `version.json`，发现新版本就在页面内提示。点「立即更新」后：

1. 下载新版本 zip，显示下载与解压进度
2. 自动替换程序文件并重启服务
3. 页面刷新后即为新版本

更新会保留 `.data` 里的账号密码、登录态和课表快照；更新失败会提示，可改用手动下载安装包。

发布新版本时要同步修改：`assets/app.js` 的 `APP_VERSION`、`version.json`、`package.json`、介绍页的版本号与下载直链。
