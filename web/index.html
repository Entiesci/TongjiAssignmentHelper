Windows 10/11 · Node.js 18+ · Edge

WHAT IT DOES

少翻几个网站，
把时间留给更重要的事。

01

校历与考试

课程、假期、调课、DDL 和考试安排，在同一张月历里看清。

02

学校通知

同步学校门户通知，搜索、只看未读、一键标为已读。

03

多平台作业

Canvas、课堂派、Educoder 作业聚合，完成状态一目了然。

04

课表与地图

右侧日期抽屉按第 1–11 节排课，课程块带上课地点附近的地图。

05

托盘与自动同步

启动时自动同步作业与通知；登录失效会尝试重新登录。

06

桌面通知

未完成作业和同步失败会提醒，点击直接打开作业页。

安静，但信息齐全。
